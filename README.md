## SISTEM MANAJEMEN INVENTARIS (SIMETRIS)

Sistem Manajemen Inventaris Toko Sembako adalah aplikasi web untuk menggantikan pencatatan persediaan menggunakan buku catatan. Aplikasi membantu pemilik dan staf mengelola produk, barang masuk dan keluar, stok minimum, kedaluwarsa, pemasok, pembelian, serta laporan persediaan.
